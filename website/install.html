RustTalk

Install guide

Installationsanleitung

RustTalk is a single download. Pick your system; every file comes from the official GitHub releases.

RustTalk ist ein einzelner Download. Wähle dein System; alle Dateien kommen aus den offiziellen GitHub-Releases.

🪟 Windows 🐧 Linux 🎮 Steam Deck

🪟 Windows

Windows 10 or 11, x64 or ARM64. No admin rights needed.

Windows 10 oder 11, x64 oder ARM64. Keine Adminrechte nötig.

  1. Download rusttalk-windows.exe from the download section (on an ARM PC: rusttalk-windows-arm64.exe).
  2. Run it. It installs itself for your user into %LOCALAPPDATA%\Programs\RustTalk and adds a Start menu entry; a desktop shortcut is optional. Settings are kept in %APPDATA%\RustTalk.
  3. If Windows SmartScreen says "Windows protected your PC", check the file first (next step), then choose More info → Run anyway. Only do this for the file from the official releases.
  4. Optional: verify the download. Next to every file in the release there is a .sha256 file. In PowerShell, in your Downloads folder: 
    (Get-FileHash .\rusttalk-windows.exe).Hash
    The output must match the long number in rusttalk-windows.exe.sha256 (upper/lower case does not matter).
  5. Start RustTalk from the Start menu, enter the server address and your name and connect. On the first connection RustTalk shows the server's fingerprint; confirm it only if it matches what the server owner gave you.
  1. Lade rusttalk-windows.exe im Download-Bereich herunter (auf einem ARM-PC: rusttalk-windows-arm64.exe).
  2. Starte die Datei. Sie installiert sich für deinen Benutzer nach %LOCALAPPDATA%\Programs\RustTalk und legt einen Eintrag im Startmenü an; eine Desktop-Verknüpfung ist optional. Die Einstellungen liegen in %APPDATA%\RustTalk.
  3. Meldet Windows SmartScreen „Der Computer wurde durch Windows geschützt“, prüfe zuerst die Datei (nächster Schritt) und wähle dann Weitere Informationen → Trotzdem ausführen. Mach das nur mit der Datei aus den offiziellen Releases.
  4. Optional: Download prüfen. Neben jeder Datei im Release liegt eine .sha256-Datei. In der PowerShell, im Download-Ordner: 
    (Get-FileHash .\rusttalk-windows.exe).Hash
    Die Ausgabe muss mit der langen Zahl in rusttalk-windows.exe.sha256 übereinstimmen (Groß-/Kleinschreibung egal).
  5. Starte RustTalk über das Startmenü, gib Serveradresse und deinen Namen ein und verbinde dich. Bei der ersten Verbindung zeigt RustTalk den Fingerabdruck des Servers; bestätige ihn nur, wenn er mit dem übereinstimmt, den dir der Server-Betreiber gegeben hat.

Updates and uninstall

Updates und Deinstallation

RustTalk looks for a new version on start and shows an Update notice; it checks the download's checksum before installing. Uninstall it like any app in Settings → Apps → Installed apps.

RustTalk sucht beim Start nach einer neuen Version und zeigt dann einen Update-Hinweis; vor der Installation prüft es die Prüfsumme des Downloads. Deinstallieren kannst du es wie jede App unter Einstellungen → Apps → Installierte Apps.

Error about the desktop shortcut? If your desktop folder is moved (for example by OneDrive), creating the desktop shortcut can fail. RustTalk is still installed: start it from the Start menu, or install again without the desktop shortcut.

Fehler bei der Desktop-Verknüpfung? Ist dein Desktop-Ordner verschoben (zum Beispiel durch OneDrive), kann das Anlegen der Verknüpfung fehlschlagen. RustTalk ist trotzdem installiert: Starte es über das Startmenü oder installiere es erneut ohne Desktop-Verknüpfung.

🐧 Linux

RustTalk for Linux is an AppImage: one file, nothing to install system-wide.

RustTalk für Linux ist ein AppImage: eine Datei, nichts wird systemweit installiert.

Install

Installieren

  1. Download rusttalk-linux-x86_64.AppImage from the download section (ARM computers: rusttalk-linux-aarch64.AppImage) and, for checking, the matching .sha256 file from the same release.
  2. Put it in a folder of your own, for example ~/Applications. It must stay writable for you: that is where in-app updates replace it.
  3. Check, make it executable and start it: 
    cd ~/Applications
sha256sum -c rusttalk-linux-x86_64.AppImage.sha256
chmod +x rusttalk-linux-x86_64.AppImage
./rusttalk-linux-x86_64.AppImage
    sha256sum must answer OK. In a file manager you can instead tick Allow executing as program in the file's properties and double-click it.
  4. Done. On start RustTalk adds itself to your app menu (with icon), so you can launch it from there next time. If you move the file later, start it once from the new place to update the entry.
  1. Lade rusttalk-linux-x86_64.AppImage im Download-Bereich herunter (ARM-Rechner: rusttalk-linux-aarch64.AppImage) und zum Prüfen die passende .sha256-Datei aus demselben Release.
  2. Lege die Datei in einen eigenen Ordner, zum Beispiel ~/Applications. Sie muss für dich beschreibbar bleiben: Dort ersetzt sie das In-App-Update.
  3. Prüfen, ausführbar machen und starten: 
    cd ~/Applications
sha256sum -c rusttalk-linux-x86_64.AppImage.sha256
chmod +x rusttalk-linux-x86_64.AppImage
./rusttalk-linux-x86_64.AppImage
    sha256sum muss OK melden. Im Dateimanager kannst du stattdessen in den Eigenschaften der Datei Als Programm ausführen erlauben anhaken und sie doppelklicken.
  4. Fertig. Beim Start trägt sich RustTalk ins App-Menü ein (mit Symbol), danach startest du es einfach von dort. Verschiebst du die Datei später, starte sie einmal vom neuen Ort, damit der Eintrag stimmt.

Good to know

Gut zu wissen

  • Push to talk in the background: pick a key in Settings → Keybinds (default F8). Your desktop asks once to allow the shortcut.
  • Updates: Settings → About RustTalk → Updates (Install update & restart). The new file is checked (SHA-256) before it replaces the old one.
  • Settings are stored in ~/.config/RustTalk/, not inside the AppImage.
  • No sound or no microphone? Make sure pipewire-pulse and pipewire-alsa (or your distribution's equivalent) are installed, then pick the devices in Settings → Voice & Audio.
  • "FUSE" error on start? Install your distribution's FUSE 2 package (e.g. libfuse2t64 on Ubuntu, fuse2 on Arch), or start it with --appimage-extract-and-run.
  • Push-to-Talk im Hintergrund: wähle eine Taste unter Settings → Keybinds (Standard F8). Dein Desktop fragt einmal, ob das Kürzel erlaubt ist.
  • Updates: Settings → About RustTalk → Updates (Install update & restart). Die neue Datei wird geprüft (SHA-256), bevor sie die alte ersetzt.
  • Einstellungen liegen in ~/.config/RustTalk/, nicht im AppImage.
  • Kein Ton oder kein Mikrofon? Prüfe, dass pipewire-pulse und pipewire-alsa (oder das Gegenstück deiner Distribution) installiert sind, und wähle die Geräte unter Settings → Voice & Audio.
  • „FUSE“-Fehler beim Start? Installiere das FUSE-2-Paket deiner Distribution (z. B. libfuse2t64 unter Ubuntu, fuse2 unter Arch) oder starte mit --appimage-extract-and-run.

🎮 Steam Deck

The Steam Deck runs SteamOS, a Linux system, so it uses the Linux AppImage. You set it up once in Desktop Mode; afterwards you can also start it from Gaming Mode.

Das Steam Deck läuft mit SteamOS, einem Linux-System, und nutzt deshalb das Linux-AppImage. Eingerichtet wird es einmal im Desktop-Modus; danach kannst du es auch aus dem Spielmodus starten.

1. Switch to Desktop Mode and check your SteamOS

1. In den Desktop-Modus wechseln und SteamOS prüfen

  1. Press the Steam button → Power → Switch to Desktop.
  2. Open Konsole (app menu → System → Konsole) and run: 
    ldd --version | head -n1
echo $XDG_SESSION_TYPE
    The first line must show 2.39 or higher, the second wayland.
  1. Drücke die Steam-Taste → Ein/Aus → Zum Desktop wechseln.
  2. Öffne Konsole (App-Menü → System → Konsole) und gib ein: 
    ldd --version | head -n1
echo $XDG_SESSION_TYPE
    Die erste Zeile muss 2.39 oder höher zeigen, die zweite wayland.

Older version or x11? Update SteamOS first (Gaming Mode: Settings → System → Software Updates). Newer SteamOS releases start Desktop Mode with Wayland; on some versions the desktop session can also be switched in Steam's developer settings. RustTalk's Linux app does not run on an X11 desktop.

Ältere Version oder x11? Aktualisiere zuerst SteamOS (Spielmodus: Einstellungen → System → Software-Updates). Neuere SteamOS-Versionen starten den Desktop-Modus mit Wayland; bei manchen Versionen lässt sich die Desktop-Sitzung auch in den Entwickler-Einstellungen von Steam umstellen. Auf einem X11-Desktop läuft die Linux-App von RustTalk nicht.

2. Download and start RustTalk

2. RustTalk herunterladen und starten

  1. Open a browser in Desktop Mode (for example Firefox from Discover) and download rusttalk-linux-x86_64.AppImage from the download section. The Steam Deck is x86_64.
  2. In the file manager Dolphin, create the folder Applications in your home folder (/home/deck) and move the file there. Your home folder survives SteamOS updates; nothing needs to be installed into the system (which is read-only).
  3. Right-click the file → Properties → Permissions → tick Allow executing file as program → OK. (In Konsole: chmod +x ~/Applications/rusttalk-linux-x86_64.AppImage.)
  4. Double-click the file to start RustTalk. It adds itself to the app menu (under Internet), so next time you can start it from there.
  5. Connect to your server and pick the Deck's built-in microphone (or your headset) in Settings → Voice & Audio.
  1. Öffne im Desktop-Modus einen Browser (zum Beispiel Firefox aus Discover) und lade rusttalk-linux-x86_64.AppImage im Download-Bereich herunter. Das Steam Deck ist x86_64.
  2. Lege im Dateimanager Dolphin in deinem Home-Ordner (/home/deck) den Ordner Applications an und verschiebe die Datei dorthin. Der Home-Ordner übersteht SteamOS-Updates; ins System (das schreibgeschützt ist) muss nichts installiert werden.
  3. Rechtsklick auf die Datei → Eigenschaften → Berechtigungen → Datei als Programm ausführen anhaken → OK. (In der Konsole: chmod +x ~/Applications/rusttalk-linux-x86_64.AppImage.)
  4. Doppelklick auf die Datei startet RustTalk. Es trägt sich ins App-Menü ein (unter Internet), danach startest du es von dort.
  5. Verbinde dich mit deinem Server und wähle unter Settings → Voice & Audio das eingebaute Mikrofon des Decks (oder dein Headset).

Typing: press Steam + X for the on-screen keyboard.

Tippen: Steam + X öffnet die Bildschirmtastatur.

3. Optional: start it from Gaming Mode

3. Optional: aus dem Spielmodus starten

  1. Still in Desktop Mode, open Steam → Games → Add a Non-Steam Game to My Library…
  2. Click Browse…, set the file type to All Files, choose /home/deck/Applications/rusttalk-linux-x86_64.AppImage and click Add Selected Programs.
  3. Go back with the Return to Gaming Mode icon on the desktop. RustTalk now appears in your library under Non-Steam.
  1. Öffne noch im Desktop-Modus Steam → Spiele → Ein Nicht-Steam-Spiel zu meiner Bibliothek hinzufügen…
  2. Klicke auf Durchsuchen…, stelle den Dateityp auf Alle Dateien, wähle /home/deck/Applications/rusttalk-linux-x86_64.AppImage und klicke auf Ausgewählte Programme hinzufügen.
  3. Zurück geht es über das Symbol Zurück zum Spielmodus auf dem Desktop. RustTalk steht jetzt in deiner Bibliothek unter Nicht-Steam.

In Gaming Mode voice and chat work, but screen sharing and background push to talk rely on Desktop Mode's system dialogs and may not be available there. Use voice activity (Settings → Voice & Audio → Input mode) instead of push to talk, or use Desktop Mode for screen sharing.

Im Spielmodus funktionieren Sprache und Chat, aber Bildschirm teilen und Push-to-Talk im Hintergrund brauchen die Systemdialoge des Desktop-Modus und sind dort eventuell nicht verfügbar. Nutze stattdessen Sprachaktivierung (Settings → Voice & Audio → Input mode) oder teile deinen Bildschirm im Desktop-Modus.

Updates work like on any Linux PC: Settings → About RustTalk → Updates (Install update & restart). The Non-Steam shortcut keeps working because the file stays in the same place.

Updates funktionieren wie auf jedem Linux-PC: Settings → About RustTalk → Updates (Install update & restart). Die Nicht-Steam-Verknüpfung funktioniert weiter, weil die Datei am selben Ort bleibt.
